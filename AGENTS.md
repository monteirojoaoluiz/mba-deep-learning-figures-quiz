# Repository Instructions

- Always use `uv` for Python commands and dependency execution.
- Always use `bun` for JavaScript commands and local static checks.
- Always use `brew` for macOS system dependencies.
- At the start of a new thread, read this file before making changes.
- When adding new generated workflows, add the relevant documentation here.

## Local LM Studio With opencode

- `opencode` local LM Studio support is configured as a custom OpenAI-compatible provider in `opencode.json` using `npm: "@ai-sdk/openai-compatible"` and `options.baseURL: "http://127.0.0.1:1234/v1"`.
- `opencode` model selection uses the configured `provider.models` map for custom providers; local LM Studio models are not inferred just from the model being downloaded in LM Studio.
- For LM Studio, verify the exact model id with `GET http://127.0.0.1:1234/v1/models`; the `provider.models` key in `opencode.json` should match that id.
- If `opencode` does not see LM Studio models, check that the LM Studio local server is actually running and listening on port `1234`.

## Figures Quiz Workflow

- The consolidated figures quiz is generated by `tools/build_figures_quiz.py`.
- Run it with:

```bash
uv run --with pymupdf tools/build_figures_quiz.py
```

- Layout: **one full viewport page per question** and **one full viewport page per answer** (scroll-snap deck). Use arrow keys, scroll, or the nav bar to move between pages.
- Local HTML: `output/figures_quiz/deep_learning_figures_quiz.html`
- GitHub Pages site: `docs/index.html` with assets in `docs/assets/`
- Extracted image assets are also written to `output/figures_quiz/assets/`.
- A generated inventory is written to `output/figures_quiz/manifest.json`.
- Use `bun` for quick static checks of the generated HTML.
- Strong answer generation uses `tools/generate_strong_answers.py`, which calls `codex exec --image` for each card and caches answers under `output/figures_quiz/strong_answers/`.
- Run strong answer generation with:

```bash
uv run tools/generate_strong_answers.py
```

- The consolidated strong-answer override file is `output/figures_quiz/strong_answers.json`; `tools/build_figures_quiz.py` uses it automatically when present.
- Publish to GitHub Pages: commit `docs/`, push to `main`, and set Pages source to the `/docs` folder on `main`.
