Exam Q1

Traditional machine-learning pipeline versus deep-learning pipeline

Strong answer

The figure contrasts two classification pipelines. In a traditional classification pipeline, the raw image first goes through a human-designed feature extraction stage: an expert decides which visual properties matter, such as edges, shapes, colors, textures, or object parts. These engineered features are then passed to a classifier, such as logistic regression, SVM, random forest, or a shallow neural network, which maps the features to a final label. The performance therefore depends heavily on the quality of the manually chosen representation. In a deep learning classification pipeline, the model receives the raw input directly, such as the image pixels, and learns both the useful features and the classifier jointly. Early layers may learn simple patterns such as edges and color contrasts, middle layers may learn parts or motifs, and later layers may learn high-level concepts such as faces, objects, or scenes. Instead of separating “feature engineering” and “classification,” deep learning combines them into one trainable system. End-to-end learning means training a model to map directly from raw input to the desired output using a single optimization objective. For example, an image classification network learns the transformation from pixels to class label by minimizing classification error, without requiring humans to manually specify intermediate features. The system discovers internal representations that are useful for the final task. The main advantage of end-to-end learning is that it reduces the need for manual feature engineering and can discover complex, hierarchical patterns that humans may not know how to encode explicitly. It often performs especially well when there is a large amount of labeled data and enough computation. However, it is less transparent, can require substantial data, and may be harder to debug than traditional pipelines where each step is explicitly designed. Deep learning is especially effective for unstructured, high-dimensional data such as images, audio, video, natural language, sensor streams, and other data where useful patterns are complex and layered. Traditional machine learning is often more suitable for smaller, structured tabular datasets, business metrics, financial records, survey data, or problems where the number of observations is limited and features are already meaningful. In MBA terms: deep learning shines when the raw data is rich but messy; traditional ML often works better when the data is clean, structured, and feature columns already carry business meaning.

Exam Q2

Two convolutional filters producing two feature maps

Strong answer

The operations in the figure are associated with a convolutional layer in a CNN. In this layer, small learnable filters, also called kernels, slide across the input image and compute local dot products. Each filter produces one feature map, so two different filters applied to the same input produce two different feature maps. The purpose of the filters is to detect useful local patterns in the image. Early convolutional filters often respond to simple structures such as edges, corners, orientations, textures, or contrast changes. Because the same filter is reused across spatial locations, the CNN can detect the same pattern anywhere in the image while using far fewer parameters than a fully connected layer. The filter weights are typically learned from data through backpropagation and gradient-based optimization, such as stochastic gradient descent or Adam. During training, the network adjusts the filter values to reduce the prediction loss. This is better than using fixed hand-designed weights because the model can discover features that are most useful for the specific task, data distribution, and objective, rather than relying on generic assumptions about what patterns matter. These convolutional building blocks are stacked to form complete CNN architectures. Lower layers usually learn simple visual features, while deeper layers combine them into more abstract patterns such as object parts, shapes, or class-specific structures. Together with nonlinear activations, pooling or striding, normalization, and final classification or regression layers, convolutional layers allow CNNs to learn hierarchical representations efficiently from raw image data.

CNN layer with receptive field and stride

Strong answer

The figure illustrates a **pooling layer**, specifically **max pooling**, in a convolutional neural network. A small window, such as a 2x2 receptive field, slides across each feature map with a chosen stride. For every window position, max pooling keeps only the largest activation, as shown by selecting `5` from the values `1, 5, 3, 2`. The purpose of pooling is to **downsample** feature maps while preserving the strongest detected features. This reduces the spatial resolution of the representation, lowers the number of computations in later layers, and helps control overfitting by making the model less sensitive to small shifts in object position. In the overall CNN architecture, pooling layers usually appear after convolution and activation layers. The convolutional layer detects local patterns such as edges, textures, or object parts; the activation introduces non-linearity; and the pooling layer summarizes nearby activations into a smaller feature map. As CNNs go deeper, repeated convolution and pooling allow the network to move from fine local details to more abstract visual concepts. Pooling is not a learned layer in the same way as convolution: it has no trainable weights. Its behavior is defined by hyperparameters such as pool size and stride. In exam terms, the key idea is that max pooling keeps the most salient local response, creating a more compact and somewhat translation-invariant representation for later classification or prediction layers.

RNN sequence architectures

Strong answer

The top-left seq-to-seq RNN maps an input at every time step to an output at every time step, so it is used when the prediction is aligned with the input sequence. Typical applications include part-of-speech tagging, named-entity recognition, frame-by-frame activity labeling, or time-series forecasting where each day/hour receives its own prediction. The top-right seq-to-vector architecture reads a whole sequence but only uses the final output or hidden state, making it suitable for sequence classification tasks such as sentiment analysis of a review, customer churn prediction from a behavior history, fraud detection from transaction sequences, or classifying an ECG signal. The bottom-left vector-to-seq architecture starts from a fixed input or initial context and generates a sequence over time. This fits generation tasks where one compact input produces multiple outputs, such as image captioning, music generation from a style vector, or generating a sequence of future values from an initial condition. The bottom-right encoder-decoder architecture is a more flexible sequence-to-sequence model for cases where the input and output sequences have different lengths and are not aligned step by step. The encoder compresses the input sequence into a context representation, and the decoder generates the target sequence, as in machine translation, text summarization, chatbot responses, or speech-to-text. A major issue with standard RNNs is the vanishing or exploding gradient problem during backpropagation through time. Because the same recurrent weights are applied repeatedly across many time steps, gradients can shrink until early inputs are almost impossible to learn from, or grow unstably and make training diverge. This makes standard RNNs weak at capturing long-range dependencies, such as when a word near the start of a sentence determines the meaning or grammar much later. This can be mitigated with gated architectures such as LSTMs and GRUs, which use gates to control what information is stored, forgotten, and passed forward, allowing important information to persist over longer sequences. Exploding gradients can also be controlled with gradient clipping, while vanishing-gradient issues can be reduced through better initialization, shorter truncated backpropagation windows, normalization, residual connections, or, in many modern sequence tasks, replacing or augmenting RNNs with attention mechanisms and Transformer-based models.

Node embedding in geometric deep learning on graphs

Strong answer

Two common tasks in geometric deep learning on graphs are node-level prediction and graph-level prediction. In node-level prediction, the model predicts a label or value for each node using both the node’s own features and information from its neighbors, such as classifying users in a social network or predicting whether a customer is likely to churn. In graph-level prediction, the model predicts a property of an entire graph, such as classifying a molecule as toxic or non-toxic, detecting fraudulent transaction networks, or estimating the overall risk of a supply-chain network. Another important graph task is link prediction, where the goal is to predict whether an edge should exist between two nodes. This is useful in recommendation systems, social networks, fraud detection, and knowledge graphs. For example, if two customers, products, or entities have similar graph contexts, the model may predict a likely future relationship between them. The illustration shows the basic idea of node embedding. Nodes from the original network, such as \(u\) and \(v\), are passed through an encoder, written as \(\text{ENC}(u)\) and \(\text{ENC}(v)\). The encoder maps each node into a vector representation in a continuous embedding space, producing vectors such as \(z_u\) and \(z_v\). Instead of representing a node only by an ID or raw features, the embedding summarizes its structural role, neighborhood, and possibly attributes. The motivation is that graphs are discrete and irregular, while most machine-learning models operate more easily on numerical vectors. Node embeddings turn graph information into compact vectors that can be used for prediction, clustering, recommendation, or visualization. Ideally, nodes that are close or structurally similar in the original graph are placed close together in the embedding space, so the geometry of the vectors preserves meaningful relationships from the network.

Exam Q6

CLIP-style vision-language model pipeline

Strong answer

Vision-Language Models, or VLMs, are deep learning models that jointly understand images and text by mapping both modalities into a shared embedding space. Instead of treating vision and language as separate tasks, a VLM learns that an image of a dog and the sentence “a photo of a dog” should have similar representations, while unrelated image-text pairs should be far apart. In the CLIP-style pipeline, the model is trained using many image-caption pairs. An image encoder converts each image into an image embedding, while a text encoder converts each caption into a text embedding. During contrastive pre-training, the model compares all image-text similarities in a batch and learns to give the highest score to the correct matching pair. This is why the matrix in the figure highlights the diagonal: those are the true image-caption matches. After training, CLIP can perform zero-shot classification. Class labels such as “dog,” “car,” or “bird” are turned into prompts like “a photo of a dog,” then encoded by the text encoder. A new image is encoded by the image encoder, and the model predicts the class whose text embedding is most similar to the image embedding. This avoids training a new classifier from scratch for every dataset, because the label meanings are provided through natural language. Common VLM use cases include zero-shot image classification, image search using text queries, automatic image captioning, visual question answering, content moderation, medical image support, robotics perception, and multimodal recommendation systems. For example, in text-based image search, a user can type “a red sports car parked at night,” and the system retrieves images whose visual embeddings are closest to that text embedding, even if the images were never manually tagged with those exact words.

Feature transformation, representation learning, and latent manifolds

Strong answer

Deep learning differs from traditional machine learning mainly because it learns the feature representation and the prediction function together. In a traditional ML pipeline, humans usually design or select features first, then train a model on those fixed inputs. Deep learning replaces much of this manual feature engineering with layers of learned transformations: early layers may detect simple patterns, later layers combine them into more abstract concepts, and the final layers use those representations for classification, regression, or decision-making. The figure illustrates this idea: data that is tangled or hard to separate in the original input space can become more organized after passing through successive layers. Each layer transforms the representation so that meaningful structure becomes easier to model. For example, examples from the same class may become closer together, while different classes become more separable. This is why deep learning is especially powerful for unstructured data such as images, text, audio, video, and sensor streams, where the useful features are difficult to specify manually. A related idea is representation learning on latent manifolds. Real-world data often lies on a lower-dimensional structure embedded inside a high-dimensional space: faces, for instance, vary according to factors such as identity, lighting, pose, and expression. Deep networks can learn latent spaces where these underlying factors are represented more smoothly and compactly. Instead of treating each input as an isolated point, the model learns a useful internal geometry of the data. The main advantages of deep learning are high predictive performance, automatic feature learning, scalability with large datasets, and flexibility across many domains. The same broad architecture family can be adapted to computer vision, natural language processing, recommendation systems, forecasting, and generative AI. Deep learning can also improve as more data and compute become available, which is a major reason it has outperformed many traditional approaches in data-rich settings. The disadvantages are also important. Deep learning typically requires large amounts of data, substantial computing power, and careful tuning of architectures, training procedures, and regularization. Models can be expensive to train and deploy, hard to interpret, vulnerable to overfitting or distribution shifts, and sometimes unreliable when used outside the conditions represented in the training data. For business use, this means deep learning is powerful when the data, infrastructure, and problem scale justify it, but simpler traditional ML methods may still be preferable when interpretability, small datasets, speed, or cost control are more important.

Typical CNN architecture

Strong answer

A typical CNN takes an image as input and processes it through a sequence of convolution, pooling, and fully connected layers. In the figure, the input image is represented as a stack of channels, such as RGB color channels. The early convolution layers scan the image with small learnable filters to detect local visual patterns such as edges, corners, textures, and simple shapes. Each filter produces a feature map, so convolution transforms raw pixels into increasingly meaningful visual representations. Pooling layers reduce the spatial size of the feature maps, for example by taking the maximum or average value in small regions. This makes the network more computationally efficient and gives it some robustness to small shifts in the image, because the exact pixel location of a feature becomes less important. After pooling, further convolution layers learn more complex patterns by combining earlier features, such as parts of objects or characteristic structures in the scene. Instead of manually designing features, such as “roof shape,” “window texture,” or “object outline,” the network automatically learns useful filters and decision rules by minimizing a loss function. During training, errors from the final prediction are backpropagated through all layers, updating both the feature-extraction filters and the final classification weights together. This is why CNNs are powerful: the whole system is optimized jointly for the target task.

Resit Q4

Recurrent neurons unrolled through time

Strong answer

Recurrent neurons are effective for sequence processing because they combine the current input with information carried forward from previous time steps. In the figure, the same recurrent layer is shown compactly on the left and “unrolled” on the right: at time step 0, 1, 2, and so on, the network receives a new input \(x_{(t)}\), produces an output \(y_{(t)}\), and passes a hidden state forward. This hidden state acts like a memory of earlier elements in the sequence, allowing the model to process data where order matters, such as text, speech, time series, customer journeys, or financial signals. A key idea is parameter sharing through time. The same weights are reused at each time step, so the model learns general patterns that can occur anywhere in a sequence rather than learning a separate model for each position. This makes RNNs flexible for variable-length inputs and outputs: they can model one-to-one, one-to-many, many-to-one, or many-to-many problems, such as sentiment classification, forecasting, translation, and sequence labeling. The main limitation of standard RNNs is that they struggle to learn long-range dependencies. During training, gradients are propagated backward through many time steps, which can cause the vanishing gradient problem: signals from far in the past become too small to meaningfully update the weights. As a result, a basic RNN may remember recent inputs reasonably well but fail to retain information from much earlier in the sequence. Exploding gradients can also occur, though these are often easier to manage with techniques such as gradient clipping. LSTMs and GRUs address this limitation by adding gating mechanisms that control what information is kept, updated, or forgotten. An LSTM uses a cell state plus input, forget, and output gates to preserve important information over longer time spans while discarding irrelevant details. A GRU is a simpler variant with reset and update gates, often requiring fewer parameters while still improving long-term memory compared with a basic RNN. In exam terms, RNNs provide sequential memory, but LSTMs and GRUs make that memory more selective and stable, enabling better learning from longer sequences.

Strong answer

Artificial neural networks were inspired by the way biological neurons receive signals, combine them, and pass on an output. In the figure, dendrites and dendritic branches receive incoming signals from other neurons through synaptic terminals. The cell body integrates these inputs, and if the combined signal is strong enough, the neuron sends an electrical impulse along the axon toward other neurons. This general idea maps loosely to an artificial neuron: inputs are received, weighted, summed, transformed by an activation function, and then passed forward. The closest analogues are conceptual rather than anatomical. Biological synapses loosely correspond to weights in an artificial neural network, because they control how strongly one neuron influences another. Dendrites resemble input connections, the cell body resembles the computation that aggregates incoming signals, and the axon resembles the output pathway. The axon hillock, where firing is triggered, is loosely analogous to an activation function deciding whether and how strongly the artificial neuron activates. The high-level parallel is that both systems improve behavior by changing connection strengths, not by following explicit hand-coded rules for every case. However, the analogy should not be taken too literally. Artificial neurons are extremely simplified mathematical units, while biological neurons are complex living cells with chemical, electrical, temporal, and structural dynamics. Real brains are not organized like clean feedforward layers, do not use backpropagation in the standard engineering sense, and involve many mechanisms beyond weighted sums and activations. The biological neuron is best understood as the historical inspiration for neural networks, not as a precise blueprint for how modern deep learning systems actually work.

ANNs performing simple logical computations

Strong answer

The figure shows artificial neurons implementing basic logical operations: identity or pass-through (`C = A`), AND (`C = A ∧ B`), OR (`C = A ∨ B`), and AND with NOT (`C = A ∧ ¬B`). In each case, inputs such as `A` and `B` are connected to an output neuron `C`, and the neuron activates only when its input pattern satisfies the logical rule. An artificial neuron can implement simple logic by assigning weights to its inputs, adding them together, and comparing the result with a threshold. For example, an AND neuron gives output 1 only when both inputs are active, so its threshold must be high enough that one active input alone is insufficient. An OR neuron uses a lower threshold, so either input can activate it. A NOT operation can be represented with an inhibitory or negative-weight connection, so that an active input suppresses the output. This illustrates the basic idea behind neural computation: neurons are simple decision units, but their behavior depends on the strength and sign of their connections. Positive weights encourage activation, negative weights inhibit it, and the threshold determines when the neuron “fires.” By choosing weights and thresholds carefully, a single artificial neuron can behave like a simple logical gate. The key limitation is that a single artificial neuron can only solve problems that are linearly separable. This means there must be a straight line, plane, or hyperplane that separates the input patterns producing output 1 from those producing output 0. Logical functions like AND and OR are linearly separable, but problems such as XOR are not. For non-linearly separable problems, a network needs hidden layers or multiple neurons combined together, allowing it to build more complex decision boundaries.

Figure 10-4

Threshold logic unit: an artificial neuron which computes a weighted sum

Strong answer

The figure shows a threshold logic unit (TLU), also called a linear threshold unit or a perceptron-style artificial neuron. It receives several input values, multiplies each input by a corresponding weight, adds them into a single weighted sum, and then passes that sum through a step function to produce an output. In notation, the neuron computes something like \(h_w(x) = step(x^T w)\), meaning the prediction is based on the dot product between the input vector and the weight vector. The inputs, such as \(x_1, x_2, x_3\), represent the features provided to the neuron. The weights, such as \(w_1, w_2, w_3\), determine how strongly each input influences the final result and whether that influence is positive or negative. During learning, the model adjusts these weights so that the weighted sum becomes larger for examples that should activate the neuron and smaller for examples that should not. A bias term is usually added to the weighted sum, even if it is not emphasized in the simplified diagram. The bias shifts the decision boundary, allowing the neuron to activate even when all input values are zero or to require a stronger signal before activating. With bias included, the computation is typically written as \(z = x^T w + b\), where \(z\) is the weighted sum before activation. The threshold or step activation function converts the weighted sum into a discrete output, often 0 or 1. If \(z\) is above a chosen threshold, the neuron “fires”; if it is below the threshold, it does not.
